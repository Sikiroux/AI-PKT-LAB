# v0.91 — Guide de diagnostic contextualisé

Dans l’onglet Guide, un bloc Commencer ici propose trois contrôles adaptés au service : poste, annuaire, DNS, fichiers, impression, FTP ou périphériques. Il fournit des observations et des branches de raisonnement, sans lire la cause injectée.

Les liens ouvrent la console correspondante ou la procédure sur le bureau technicien du même environnement. Les consoles ouvertes par lien ne modifient pas automatiquement les comptes, configurations ou fichiers.

Le Guide générique, la méthode d’accès distant et les indices progressifs existants restent disponibles. La correction complète reste une action séparée.

Les tests vérifient les sept familles, les alias impression/transfert, les liens isolés par environnement et l’indépendance vis-à-vis des champs de panne cachés. Le rendu visuel doit encore être contrôlé dans Chrome.

Voir ROADMAP.md pour l’état réel des huit étapes, les limites et les priorités.
