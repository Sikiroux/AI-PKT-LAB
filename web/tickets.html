Mes labs

En mode Reproduire une panne, le réseau initial est sain et le fichier de correction montre une panne reproduite. Pour les autres modes, le réseau de référence représente le socle sain. Les missions « Ajouter un serveur web », « Isoler les invités », « Bloquer un poste précis » et « Déployer DHCP centralisé » fournissent une topologie de correction configurée dans correction.pkt ; le bail DHCP est obtenu après ouverture dans Packet Tracer. Pour les autres missions d’ajout, la correction textuelle indique les extensions à réaliser.
