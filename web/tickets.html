Ateliers et tickets de dépannage PKT / PKA

Retrouve ici le générateur historique de tickets de dépannage, les ateliers, les exercices mixtes et la reproduction de pannes. Chaque exercice possède son propre réseau PKT/PKA, sa feuille HTML, ses indices et sa correction. Il ne crée pas de ticket dans l’entreprise active. Les scénarios de services et Meraki nécessitent encore une validation dans ta version de Packet Tracer.

Le niveau filtre la difficulté minimale des scénarios. Le nombre de pannes concerne seulement les scénarios réseau classiques ; un scénario mixte associe un atelier et une panne compatible.

Mes labs

En mode Reproduire une panne, le réseau initial est sain et le fichier de correction montre une panne reproduite. Pour les autres modes, le réseau de référence représente le socle sain. Les missions « Ajouter un serveur web », « Isoler les invités », « Bloquer un poste précis » et « Déployer DHCP centralisé » fournissent une topologie de correction configurée dans correction.pkt ; le bail DHCP est obtenu après ouverture dans Packet Tracer. Pour les autres missions d’ajout, la correction textuelle indique les extensions à réaliser.
